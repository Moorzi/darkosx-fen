// 01 · overview

Substance before spectacle.

This build does not chase novelty for its own sake. It keeps what the community already trusts, then improves the parts you meet every time you power on: menus, setup, lock screen, and the quiet choices behind performance.

>_

Front end

EmulationStation is rebuilt with a terminal-leaning theme, a tile Control Centre, and a clearer system panel. Navigation stays familiar; the presentation is new.

01

First power-on

A short wizard walks through the essentials on first boot. Confirm with A and continue. No hand-editing of configuration files is required.

◐

Lock backgrounds

Ten original compositions, several of them celestial. Choose one under Display & Sound; the selection persists across sleep and restart.

⚡

Measured policy

Frequency defaults stay inside the clock ceiling the hardware already publishes. Nothing is overvolted. Claims wait on measurement.

⇄

Network transfer

The Samba share and web file browser that the community relies on are retained, so libraries can still arrive over Wi-Fi.

⛨

Public package

The release image carries neither ROMs nor copyrighted console BIOS. You supply dumps from hardware you own.
