dArkOSX Fen

Your handheld. Reprogrammed.

Custom firmware for the R36S / R36XX. A neon-lit EmulationStation, a guided first boot, lock backgrounds you actually want to look at, and performance-minded defaults.

// 01 · what's inside

Built for the pocket.

Everything you already rely on stays put. Fen adds the look, the polish and a careful tuning pass on top.

>_

Neon EmulationStation

A rebuilt front end with a terminal-style theme, tile Control Centre and a fresh system panel.

01

First-boot wizard

A guided setup the first time you power on. Press A and go: no config files, no guesswork.

◐

Lock backgrounds

Ten original lock screens, four of them deep-space. Cycle them from Display & Sound.

⚡

Performance-minded

Sensible defaults within the clocks the base already ships. No overvolting.

⇄

Samba & file browser

The community Samba share and web file browser are kept, so you can drop files over Wi-Fi.

⛨

Clean public image

No ROMs and no copyrighted console BIOS in the public package. Bring your own dumps.

// 02 · the look

Dark. Sharp. Green.

Captured from a real R36S running the current Fen build.

// 03 · lock screen

Ten ways to lock it.

Pick one in Display & Sound → Lock Background. Tap a tile to preview it.
