The R36S image that feels finished on first boot.

// 01 · overview

More than a theme. A handheld that feels finished.

dArkOSX-Fen is a community build on dArkOS for genuine R36S. The look, the boot, the day-to-day, and the places stock leaves unfinished. Heavier systems get real attention (Dreamcast especially, with PlayStation and N64 in good shape). Lighter classics stay silky. RAM Plus steps in when the built-in 1 GB fills up. MSX works out of the box with free C-BIOS. And the optional lock screen with device PIN lets you make the device feel like yours.

Grab them from the v0.1.0-alpha release.


      

        
1 · Join the two parts

        
# Linux / macOS
cat dArkOSX-Fen_R36S_v0.1.0-alpha.img.xz.zip.001 \
    dArkOSX-Fen_R36S_v0.1.0-alpha.img.xz.zip.002 \
  > dArkOSX-Fen_R36S_v0.1.0-alpha.img.xz.zip

# Windows (Command Prompt)
copy /b dArkOSX-Fen_R36S_v0.1.0-alpha.img.xz.zip.001+dArkOSX-Fen_R36S_v0.1.0-alpha.img.xz.zip.002 dArkOSX-Fen_R36S_v0.1.0-alpha.img.xz.zip

      


      

        
2 · Verify (optional, recommended)

        
# Linux
sha256sum -c dArkOSX-Fen_R36S_v0.1.0-alpha.img.xz.zip.sha256

# macOS
shasum -a 256 -c dArkOSX-Fen_R36S_v0.1.0-alpha.img.xz.zip.sha256

# Windows (PowerShell). Compare to the hash in the .sha256 file
Get-FileHash .\dArkOSX-Fen_R36S_v0.1.0-alpha.img.xz.zip -Algorithm SHA256

      


      

        
3 · Unzip, decompress, flash

        
# Linux / macOS
unzip dArkOSX-Fen_R36S_v0.1.0-alpha.img.xz.zip
# optional verify of the xz:
#   sha256sum -c dArkOSX-Fen_R36S_v0.1.0-alpha.img.xz.sha256
#   (macOS: shasum -a 256 -c …)
xz -dk dArkOSX-Fen_R36S_v0.1.0-alpha.img.xz

# Flash with balenaEtcher, or:
sudo dd if=dArkOSX-Fen_R36S_v0.1.0-alpha.img of=/dev/sdX bs=4M status=progress conv=fsync
# Double-check /dev/sdX. Wrong device wipes the wrong disk.

# Windows: unzip with 7-Zip or File Explorer, decompress the .xz with 7-Zip,
# then flash the .img with balenaEtcher (https://etcher.balena.io/).

// 05 · naming

    
dArkOSX-Fen, dArkOS, and “dark OS”

    
Similar names, different projects. dArkOSX-Fen is this independent R36S community build, published as darkosx-fen. dArkOS (christianhaitian/dArkOS) is the upstream handheld firmware it is based on. For stock downloads and docs, use upstream.

    
Searching for dark OS or darkos can also surface ahmad1abbadi/darkos, a separate Wine-on-Android project. That is not this handheld firmware.

    
Upstream dArkOS on GitHub · This project: Moorzi/darkosx-fen

  


  
No games, ROMs, or copyrighted BIOS files are included. Free MSX C-BIOS ships in the image. Use only material you are legally entitled to use. Unofficial community build on dArkOS; not affiliated with or endorsed by any console manufacturer.





Questions and answers
Before you choose a build.


What is dArkOSX-Fen?


dArkOSX-Fen is a community build of custom firmware for genuine R36S handhelds (RK3326), based on dArkOS. Built and tested on R36S; R36XX is not separately validated yet. Dynamic boot, redesigned EmulationStation theme, tiled Control Centre, guided first-boot setup (welcome, name, Wi-Fi, PIN, lock, BIOS help), optional lock screen with a device PIN, free MSX C-BIOS, RAM Plus, and Wi-Fi file transfer.


Is dArkOSX-Fen the same as dArkOS or dark OS?


No. dArkOS is the upstream handheld firmware. dArkOSX-Fen is a separate community build based on it, not an official upstream release. The similarly named Android darkos project is unrelated.


Who is this image for?


Built and tested on a genuine R36S (RK3326), typically V21 / V22-ish. R36XX owners can try it, but it is not separately validated yet. Clones usually want RE or a clone-specific build instead.


What about the lock screen?


dArkOSX-Fen includes an optional lock screen with ten backgrounds and an optional device PIN. Set it under Display & Sound when you want the menu to stay yours.


Does MSX work without adding BIOS?


Yes. Free C-BIOS ships in the image, so MSX loads without hunting BIOS packs. No ROMs are included. Copyrighted BIOS for other systems (GB, GBC, GBA, PSX, NDS and similar) stays user-supplied.


Which files do I need to download?


Only the two zip parts are required: dArkOSX-Fen_R36S_v0.1.0-alpha.img.xz.zip.001 and .002. The PARTS.sha256, SHA256SUMS and .sha256 files are optional but recommended so you can verify before flashing.


How do I install from GitHub?


See Install from GitHub: join the two zip parts, optionally verify checksums, unzip and decompress to .img, then flash with balenaEtcher or dd. Back up your card first. Match board and panel in the image boot selector (separate from the first-boot wizard). Change the default ark / ark credentials before sharing Wi-Fi.
