// 01 · overview

R36S / R36XX custom firmware, rebuilt from the kernel up.

dArkOSX is a ground-up rebuild based on dArkOS, not a skin on stock firmware. The work reaches kernel, bug fixes, hardware communication paths and audio, with a performance-focused aim. MSX works out of the box because this image ships free C-BIOS — stock MSX does not. RAM Plus adds 2 GB of extended memory when onboard RAM runs out — extra headroom for demanding games like N64 and Dreamcast. Paired FPS (37 titles): mostly a tie; Dreamcast Crazy Taxi 2 is a clear Fen win (+27%). The revised EmulationStation interface and setup experience sit on top of that stack.

>_

Front end

A terminal-style EmulationStation theme adds a tiled Control Centre and a revised system panel while retaining familiar navigation.

01

First power-on

A guided first-boot wizard presents the initial settings. Use A to confirm each step.

◐

Lock backgrounds

Choose from ten backgrounds under Display & Sound. The selection is saved across sleep and restart.

⚡

MSX, ready to play

Free C-BIOS ships in the image, so MSX works out of the box. Stock does not include the BIOS MSX needs. Copyrighted GB / GBC / GBA / PSX / NDS BIOS stay user-supplied; first-boot help lists what is missing.

◎

Verified rootfs fixes

Root btrfs remounts with working compression (stock’s zlib:1 is rejected on this kernel). zram boot-order cycle fixed; IPv6 NetworkManager flood off; udev-settle deps removed; stray continue in perf scripts fixed. Paired FPS (37 titles) is below.

▣

RAM Plus

2 GB of extended memory — virtual RAM that kicks in when onboard memory runs out. Extra headroom for demanding games like N64 and Dreamcast on a 1 GB handheld.

⇄

Network transfer

Samba sharing and the web file browser stay available for Wi-Fi transfers — the same stock networking model (change the default password before sharing a network).

⛨

Public package

No ROMs. Free MSX C-BIOS is included; copyrighted GB / GBC / GBA / PSX / NDS BIOS are not — supply your own where required. First-boot help explains what is needed.

// 05 · naming

    
dArkOSX, dArkOS and “dark OS”: which project?

    
The names are similar, but the projects are distinct. dArkOSX is this independent R36S / R36XX custom firmware build, published in darkosx-fen. dArkOS, maintained at christianhaitian/dArkOS, is its upstream Linux handheld foundation. For stock dArkOS downloads, updates and documentation, use upstream rather than this build.

    
Searching for dark OS or darkos can also lead to ahmad1abbadi/darkos, a separate Wine-on-Android project. That is not this Linux handheld firmware; dArkOSX does not provide its Android environment.

    
Upstream dArkOS on GitHub · This project: Moorzi/darkosx-fen

  


  
No games, ROMs, or copyrighted BIOS files are included, and none will be. Supply only dumps taken from hardware you own. This is an unofficial community build atop dArkOS; it is not affiliated with or endorsed by any console manufacturer.




Questions and answers
Before you choose a build.
What is dArkOSX?
dArkOSX is an independent, ground-up R36S and R36XX firmware rebuild based on dArkOS. It includes kernel work, bug fixes, hardware communication paths and audio work, plus free MSX C-BIOS so MSX works out of the box, alongside its revised interface.
Is dArkOSX the same as dArkOS or dark OS?
No. dArkOS is the upstream Linux handheld firmware. dArkOSX is a separate community build based on it, not an official upstream release. The similarly named Android darkos project is unrelated.
Is dArkOSX faster than stock dArkOS?
Paired FPS on 37 titles (same ROMs): most systems are a near tie (median Fen +0.4%). Clear Fen win on Dreamcast Crazy Taxi 2 (42.1 vs 33.1 fps, +27%). PSX ~+2–3%, high N64 +3%, high NES / low GBA ~+3%. Stock is slightly ahead on mid GBA (−1.2%) and high GBC (−0.8%). Mean +1.35% is skewed by Dreamcast — not a blanket “faster” claim. MSX also works out of the box with free C-BIOS.
Does MSX work without adding BIOS?
Yes on this build — free C-BIOS is included, so MSX loads out of the box. Stock dArkOS MSX typically does not, because it ships without that BIOS. Copyrighted BIOS for other systems (GB, GBC, GBA, PSX, NDS and similar) are not included.
Can I download the R36S / R36XX image?
A public alpha is on GitHub. The site download button stays Coming Soon until the ≤2-part zip package is complete and Connor approves promoting it.
